1. Introduction & Architecture Overview

When uploading large files, video libraries, or uncompressed media backups to Telegram, standard interfaces suffer from major drawbacks: network drops cause uploads to fail and restart from byte 0, uploaded videos require the recipient to download the entire file before playback, and duplicate files waste channel bandwidth and storage.

Telegram Resumable Media Uploader solves these issues through a dual-tier architecture:

  • Stateful MTProto Chunking: Files are split into configurable chunks (typically 256 KB or 512 KB). Each chunk sent to Telegram's data centers is indexed into a local SQLite database (uploader.db). If interrupted, uploads resume immediately from the exact chunk without re-transmitting already received data.
  • Lossless Faststart Optimization: For videos (MP4, MOV, MKV), the metadata container index (moov atom) is placed at byte 0 via FFmpeg copy stream. This enables Telegram's native player (AVPlayer on iOS/macOS, ExoPlayer on Android) to stream videos on tap without downloading.
  • Persistent Dialog Cache: Discovered Telegram groups, supergroups, and channels are permanently indexed locally so destination dropdowns remain accessible even after Telegram's 24-hour update window expires.

3. Setting Up Your Telegram Bot & API Credentials

To run this application with your own Telegram account, you need two items: a Bot Token and optional Telegram API Credentials.

1 Create Your Telegram Bot via @BotFather
  1. Open Telegram and search for @BotFather (verified bot with blue checkmark).
  2. Send the command: /newbot
  3. Follow the prompts to enter a Display Name (e.g. My Media Uploader) and a Username ending in bot (e.g. my_personal_uploader_bot).
  4. BotFather will reply with your HTTP API Token (e.g. 123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ). Keep this token private!
  5. Send /setjoingroups to @BotFather → select your bot → choose Enable so your bot can be added to your groups.
2 Get Your Telegram API ID and Hash (Recommended for MTProto 2GB+ uploads)
  1. Log in to https://my.telegram.org using your Telegram phone number.
  2. Click on API development tools.
  3. Fill out the form (App title and Short name can be anything simple like MyUploader).
  4. Copy your App api_id (an integer like 12345678) and App api_hash (a 32-character string).
💡 What if my.telegram.org gives an "ERROR"?
If Telegram web returns a generic error when generating an API hash, disable ad-blockers, try an incognito window, or simply leave the default API ID/Hash in config.example.json (which uses Telegram's open-source desktop credentials) and enter just your Bot Token.

4. Configuring Groups and Channels

Your Telegram Bot needs permission to post in your target groups and channels:

A Adding Bot to a Group or Supergroup
  1. Open your Telegram Group → Tap Group Settings → Add Members.
  2. Search for your bot's username (e.g. @my_personal_uploader_bot) and add it.
  3. Promote the bot to Administrator (ensure Send Messages and Post Media permissions are checked).
  4. Crucial Step: Send any single message into the group (e.g. /start or hi). This allows the bot to register the group's Chat ID.
B Adding Bot to a Channel
  1. Open your Telegram Channel → Administrators → Add Administrator.
  2. Search for your bot and grant Post Messages permission.
  3. Post any test message in the channel so the bot detects it.

5. Quickstart: Running the Web App & Dashboard

Installation

# 1. Clone the repository
git clone https://github.com/amolvbharambe/telegram-media-uploader.git
cd telegram-media-uploader

# 2. Run the startup script (automatically configures venv and dependencies)
chmod +x run.sh
./run.sh

The web server will start and be available at http://localhost:8080.

Logging In & Configuration

  1. Open your browser to http://localhost:8080 and click the Telegram & Settings tab.
  2. Select Bot Token Login and paste your Bot Token from @BotFather.
  3. Click Connect Bot. The connection badge in the header will turn green: ● Connected.

Uploading Media

  • Drag & Drop: Drag multiple files or entire folders directly into the drop zone.
  • Local Disk Path: Enter any folder path (e.g. /Users/name/Videos) to scan and queue gigabytes of files with zero browser upload delay.
  • Destination Dropdown: Select your Telegram Group or Channel from the dropdown list.
  • Send Options: Leave Send as Raw Document unchecked to enable instant inline video streaming.

6. Native Android App Installation & Usage

A standalone native Android application (built with Jetpack Compose and Material 3) is included in the GitHub repository releases as TelegramUploader.apk.

1 Installation

Download TelegramUploader.apk from the GitHub Releases page or directly from your running web server at http://<your-computer-ip>:8080/download/app.apk. Install the APK on your Android device (enable "Install unknown apps" if prompted).

2 Configuration

Open the app → Navigate to Settings → Enter your Bot Token → Tap Save & Test Connection. The app verifies your bot credentials directly with Telegram's servers.

3 Queueing from Phone

Tap Select Media → Pick photos, videos, or documents from your phone gallery or file manager. The app automatically scans for existing duplicates in the selected Telegram group and uploads files with live progress notification bars.

7. Instant Video Streaming & Duplicate Prevention

How Video Streaming Works (Technical Details)

Normally, camera recordings (from iPhones, Android phones, and dashcams) write video metadata at the end of the file in the mdat → moov structure. When uploaded to Telegram without faststart, the Telegram client cannot read video duration or keyframe tables until 100% of the file is downloaded.

This application runs an automated inspection on every video: 

ffmpeg -i input.mov -c copy -movflags +faststart output.mp4

This moves the moov atom to byte 0. Because it uses stream copying (-c copy), there is zero re-encoding, zero compression, and 100% exact original bit-for-bit quality preserved in milliseconds. It then attaches DocumentAttributeVideo(supports_streaming=True) so Telegram plays the video inline immediately upon tapping.

Group Duplicate Checking

Before starting an upload batch, tap 🔍 Check Duplicates in the Web UI or Android app. The engine:

  1. Scans Telegram group messages and local indexed task records.
  2. Matches incoming files by exact filename, byte size, and content signatures.
  3. Marks existing files with warning pills indicating the exact Telegram Message ID where the file already resides.
  4. Provides a one-click ⚡ Skip Duplicates button to prevent wasting data.

8. CLI Tool (Headless & Scripting Usage)

For power users, automated server backups, and headless environments, use cli.py:

# Authenticate with Bot Token
python cli.py auth --bot-token "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"

# Upload a single file with live speed & ETA
python cli.py upload /path/to/movie.mp4 --chat -1001234567890

# Upload an entire directory recursively
python cli.py upload /path/to/media/ --chat @mychannel -r --concurrency 4

# View queued and resumable tasks
python cli.py queue

# Resume interrupted tasks after a connection drop
python cli.py resume

9. Troubleshooting, FAQ & Privacy Notice

⚠️ Why did my groups disappear from the Destination dropdown?
Telegram's Bot API (getUpdates) purges incoming chat events after 24 hours of inactivity. In version 1.1.0+, all discovered groups are permanently saved in your local SQLite database (known_dialogs). If a group was not detected, simply post any message into that group (e.g. hi) and click the 🔄 refresh icon.
🔒 Privacy & Data Security Commitment
This repository does not contain any hardcoded bot tokens, user credentials, personal phone numbers, or private chat IDs. All session databases, uploaded media caches, and authentication keys are stored exclusively in the local data/ folder on your computer, which is strictly excluded from version control.
